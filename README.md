# Seedling Garden 🌱

Расширение для SillyTavern: цветок в горшке и питомец растут с каждым сообщением в чате. Очки за сообщения тратятся в магазине.

## Установка
1. Залей папку на GitHub (в корне репозитория: `manifest.json`, `index.js`, `style.css`, `assets/`).
2. SillyTavern → Extensions → Install extension → вставь ссылку на репозиторий.
3. Перезагрузи страницу.

Вручную: положи папку в `SillyTavern/public/scripts/extensions/third-party/seedling-garden`.

## Как играть
- Каждое сообщение даёт очки (по умолчанию +3 за твоё, +2 за сообщение персонажа) и растит цветок и питомца.
- Вода и свет (у питомца сытость и радость) убывают с каждым сообщением. Без них рост замедляется, цветок вянет.
- Кнопки WATER / SUN / GROW! работают для цветка, FEED / PLAY / GROW! для питомца. Переключатель PLANT / PET выбирает цель.
- Кнопка с магазином: семена (разные цвета, радужный редкий), яйца питомцев, товары для ухода.
- Пришелец: редкий гость, иногда появляется в магазине на время. Ещё его можно получить из яйца-загадки с малым шансом.
- Клик по цветку или питомцу даёт смешной комментарий по сюжету. В настройках можно включить ИИ-комментарии.
